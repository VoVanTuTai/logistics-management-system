# @NEXUS/guest-web - Customer Portal & Universal Tracking

Cổng thông tin Khách hàng & Tra cứu Vận đơn Toàn quốc hợp nhất.

## Tính năng
- Tra cứu vận đơn trực tiếp cho khách vãng lai và người nhận hàng (hỗ trợ `?track=...` và `/track/:code`).
- Thanh tiến trình đồ họa 5 giai đoạn & nhật ký hành trình trực quan.
- Ước tính cước phí tự động và tra cứu danh bạ bưu cục toàn quốc.
- Tạo vận đơn và quản lý lịch sử đơn hàng cho khách hàng có tài khoản.

## Run

```bash
npm install
npm run dev
```

Mặc định chạy tại `http://127.0.0.1:5175`.
